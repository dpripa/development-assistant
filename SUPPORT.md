# Support

Choose the channel that matches the request so it reaches the right workflow.

## Usage and Installation Help

Use the [WordPress.org support forum](https://wordpress.org/support/plugin/development-assistant/)
for installation, configuration, and general usage questions.

Before posting:

- update to the latest stable Development Assistant version;
- include WordPress and PHP versions;
- describe the expected and actual behavior;
- list relevant themes or plugins when a conflict may be involved;
- remove credentials, personal data, and private log contents.

## Bugs and Features

Use GitHub Issues for reproducible bugs in the current codebase and focused
feature proposals. Select the appropriate issue form and provide all requested
details.

GitHub Issues are not a private support channel and are not suitable for site
credentials, production data, or undisclosed security problems.

## Security

Report suspected vulnerabilities privately according to
[SECURITY.md](SECURITY.md).

## Scope

Project support cannot provide emergency production administration, recover
deleted data, debug unrelated proprietary extensions, or guarantee compatibility
with every hosting environment. Focused diagnostic information and reproducible
steps make assistance more likely.
